Backup & Transfer

Export everything (tanks, logs, limits, media) as a JSON file, then import it on another device. Import merges safely — new entries are added and newer versions win, so two devices can each add entries and exchange files without losing anything.

Trash — deleted tanks & entries

Deleted items are kept here so deletions sync across devices and never appear in logs or reports. Restore anything, or empty the bin permanently.

Desktop Snapshots

Automatic on-disk snapshots of the app state (at most one per 10 minutes, newest 12 kept). Restoring first snapshots the current state, then reloads the app.

Voyage

Voyage number and its legs (From → To with dates). The current leg shows in the top bar and is stamped on every status, highlight and entry/inspection registration. Tap a leg to mark it current.

Bulk paste legs (Excel)

Columns in this order: From · To · Departure · Arrival · Last operation · Details. Dates accept “05-Jul-2026 00:00 LT”, dd/mm/yyyy or yyyy-mm-dd (time & LT ignored). Tab-separated from Excel, or use “|”. The header row is skipped automatically. Pasted legs are added after any existing legs of:

Tank List — Set Up a New Ship (Paste from Excel)

Columns: Tank name ⇥ Category ⇥ Side. Category: CARGO / BALLAST / FW / COFF. Side: PORT / STBD / FULL (full-width). Existing tanks are matched by name — their logs are kept and only category/side update if changed; new names are added in paste order. Nothing is ever deleted by this import.

Change Log

Every status, highlight, entry/inspection and bulk change — timestamped with the voyage/leg in force at the time. Merges across devices like any other record.

Bulk Tank Data — Paste from Excel

Columns (tab-separated): Tank ⇥ Status ⇥ Highlight ⇥ Colour ⇥ L3C last ⇥ 2nd last ⇥ 3rd last. Colour: 1 Amber · 2 Blue · 3 Violet · 4 Teal · 5 Pink (names also accepted). Blank cells never overwrite existing values; a single dash "-" clears that field. L3C applies to cargo tanks only.

Last 3 Cargoes (L3C) — Paste from Excel

Paste tab-separated rows: Tank name ⇥ Last cargo ⇥ 2nd last ⇥ 3rd last (one tank per line). Copying cells straight from Excel gives this format automatically.
